# Mayham Accounts — Solid UI redesign

This version starts with the full Macro Mayham UI update (upstream RoALT app and native backend retained). Changes:

- Replaced the goo/liquid navbar with solid, square-rounded selected navigation tabs.
- Removed the expanding liquid ripple, view blur/melting effects, glass backdrop blur and frosted transparency from key panels and dialogs.
- Created a matte, structured desktop visual style: distinct titlebar, crisp outlined cards, flatter account rail, restrained colour.
- Changed new-install defaults to glow 0 and 10px corners; the theme editor and its preset colours remain available.
- Kept account/session features, custom backgrounds, news filtering, About Macro Mayham, upstream developer credit, license, and RoALT Discord link.

Existing installations may retain their saved theme glow/corner settings; choose 'Mayham Violet' and adjust them in Theme Studio if desired.

Build: Windows / Tauri as in the existing README. This archive is full source, not a compiled Windows executable.
