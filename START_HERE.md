# Mayham Accounts — RoALT-based edition

This is the **full RoALT 1.1.0-derived application**, not the earlier lightweight native preview. It keeps the original dashboard, account list, game launching, settings, security, navigation, and app architecture. Changes are limited to independent Mayham branding/icon, selectable and custom appearance themes, and visible upstream attribution in Settings → About.

## Make one Windows installer for your community

1. Put the contents of this `Mayham-Accounts` folder in a GitHub repository (keep the `.github` directory).
2. On GitHub, open **Actions → Mayham Accounts - Windows Installer → Run workflow**.
3. When it finishes successfully, download **Mayham-Accounts-Windows-Installer** from the workflow's Artifacts section. It contains a normal Windows installer `.exe` generated by Tauri/NSIS.
4. Distribute that installer. **Community members do not need GitHub, CMD, Node, Rust or Perl.**

This workflow is supplied as source and has not been run or Windows-tested here. A code-signing certificate is not included; unsigned builds may show Windows SmartScreen warnings.
