# Mayham Accounts — UI refresh

- Original RoALT account-management screens and behavior retained; refreshed panel surface styling.
- Settings → About: standalone Macro Mayham / Mayham Accounts information and separate original developer acknowledgement with Discord and source links.
- Removed pictured RoALT-only About rows: usage-count control, Rolimons values control, RoALT release row, and RoALT support/Donate row. The underlying Rolimons integration was not deleted from the backend.
- Removed RoALT promotional online-counter and Discord/donate shortcuts from the title app menu. Other common shortcuts stay.
- News excludes RoALT release items and their failed-source warnings; Roblox DevForum, Roblox Newsroom and Roblox client entries remain unchanged.
- The upstream RoALT automatic-update polling is disabled; the default self-update setting is off. Configure a Mayham-owned updater before enabling updates. The old update implementation is retained internally but not surfaced as an About control.
- Original MIT LICENSE, NOTICE and source attribution remain in project.
